# Dados B3 — Cotações Ibovespa

**Fonte:** Kaggle  
**Link:** https://www.kaggle.com/datasets/felsal/ibovespa-stocks

## Como baixar

1. Acesse o link acima (requer conta gratuita no Kaggle)
2. Clique em **Download**
3. Renomeie o arquivo para `ibovespa_stocks.csv`
4. Salve nesta pasta: `10_dados/b3/ibovespa_stocks.csv`

## Formato esperado

O arquivo deve conter colunas de ticker, data, abertura, fechamento, máximo, mínimo e volume das ações do Ibovespa.
