# Dados CVM — Empresas e DFP

**Fonte:** Comissão de Valores Mobiliários (dados abertos)

## Arquivos necessários

### cia_aberta_cad.csv — Cadastro de empresas abertas
https://dados.cvm.gov.br/dados/CIA_ABERTA/CAD/DADOS/cia_aberta.csv

### dfp_receita_lucro.csv — Demonstrações Financeiras (DRE)
https://dados.cvm.gov.br/dados/CIA_ABERTA/DOC/DFP/DADOS/

Acesse o link acima, baixe o arquivo DRE consolidado mais recente  
(ex.: `dfp_cia_aberta_DRE_con_2023.csv`) e renomeie para `dfp_receita_lucro.csv`.

## Como baixar

Acesse cada link no navegador e salve os arquivos nesta pasta: `10_dados/cvm/`
